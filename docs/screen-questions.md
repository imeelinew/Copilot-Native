# 截图解题

显示／收起窗口：Control + Option + Command + Space（⌃⌥⌘Space）。应用在前台且主窗口可见时，按下隐藏应用；在后台、隐藏、窗口最小化或已关闭时，按下唤起主窗口。收起不会退出应用或停止截图解题；应用需保持运行。原截图快捷键 ⌃⌥⌘S 不变。

快速显隐：Option + Space（⌥Space），与原显隐键控制同一当前窗口／浮窗，其他应用中也可用。浮窗显隐不改变浏览器或编辑器的输入焦点；如快捷键被其他应用占用，会提示注册失败，原来的四键显隐仍保留。

- 全屏截图：Control + Option + Command + S（⌃⌥⌘S），仅累积截图，不发送。滚动页面后继续按即可补充题目。
- 区域截图：Control + Option + Command + 4（⌃⌥⌘4），在鼠标所在显示器内拖拽框选，松开累积截图，不发送；Esc、右键或再次按同一快捷键取消，保留原有截图。
- 发送快捷键：Control + Option + Command + Return（⌃⌥⌘Return），按截图顺序将待发送图片一次提交给模型，合并题干再解答。两个快捷键都可在后台使用。
- 清空快捷键：Control + Option + Command + Delete（⌃⌥⌘⌫，退格键），清空累计的待发送截图及尚未完成的截图，不影响正在生成的解答或已显示的答案；可在后台使用。
- 全屏截取鼠标所在显示器的完整画面；区域截图仅采样框选范围。两者都排除整个 Copilot Native，可混合累积后发送。高分辨率截图可附带重叠局部图，以帮助读清小字。
- 在工具栏打开“截图解题”查看流式答案。全屏截图和发送不激活应用、不切页、不显示预览。区域截图会显示本地框选遮罩，完成后消失，不播放声音，不调用系统截图工具条。
- 图片只在内存中处理，不写入截图文件或剪贴板；按发送快捷键后才提交到配置的模型接口。最多保留 6 次截图（含正在发送的一批），图片总量上限为 24 MiB。
- 使用前先通过“截图解题”页的“授权屏幕录制”完成系统授权。快捷键触发时若未授权，只在应用页内显示错误，不主动弹授权框。macOS 自己的权限提示和捕获指示由系统控制。
- 发送会等待此前尚未完成的截图；之后新截的图留作下一批，不打断正在生成的解答。发送成功后将该批图片和答案保留在本题会话中，供后续截图排错；失败或点击“停止”则保留待发送截图，便于重试。
- 页面显示待发送张数，可“一起发送”或“清空截图”；清空不会停止正在发送的另一批。退出应用会清除内存中的截图、答案和排错会话，不自动保存到题库。
- 回答默认采用应届生能手写和解释的基础方案：单一解法、最少状态、必要的 Hook，避免额外抽象、多文件、复杂类型和未要求的优化；保留题目功能、正确依赖和资源清理。
- 回答先说明“怎么填写”：在截图可确认的代码框、文件或单元格中写什么，以及新建、替换、补全和保留哪些内容。项目题按文件分步给出代码，在线判题保留平台签名；看不清的项目路径会明确标为假设或建议。
- 腾讯会议整屏共享时继续启用“屏幕共享隐藏（实验性）”，关闭腾讯会议的“视频流畅度优先”。截图结果仍显示在被排除的应用窗口中。

## 区域框选与共享隐藏

区域框选使用本应用的非激活透明面板，在第一次显示前设置共享排除；关闭普通窗口排除选项也不会解除选区面板保护。遮罩、边框和操作提示全部绘制在这个面板内，不切换系统鼠标为截图十字光标，不使用系统截图工具。腾讯会议可能仍显示正常鼠标移动，但不应出现选框、遮罩或提示；需在接收端对新选区面板验证，保持关闭“视频流畅度优先”。

框选不收起悬浮答案或主窗口；完成或取消时仅关闭选区遮罩，不重新隐藏应用，也不抢输入焦点。截图仍排除整个应用，因此图片中不会包含悬浮答案。区域截图不弹预览、不进剪贴板、不落盘；发送之前不上传图片。

每次选区限定在快捷键触发时鼠标所在的一个显示器，拖出该屏会裁剪到该屏边界；需要另一个屏幕的内容，取消后把鼠标移到那块屏再按快捷键。最小选区为8×8逻辑点，太小可重画。若显示器配置变化会取消或拒绝旧选区，不自动改截全屏。截取使用显示器局部逻辑坐标，按当前像素比例保留清晰度，输出长边最大4096像素。

开始框选时即在队列预留位置和一张额度。框选期间发送会等本次选择完成；随后截图属于下一批。清空会取消正在框选的区域，并使此前未完成截图失效。已达6张限额时不会打开遮罩。Esc若被其他程序占用，遮罩会提示使用右键取消。

## 同题截图排错

先通过 ⌃⌥⌘S 累积原题，再按 ⌃⌥⌘Return 取得答案。运行、编译或提交报错后，把错误信息及相关代码放到屏幕上，按 ⌃⌥⌘E（Control + Option + Command + E）：直接截图并发送排错，无需再按发送键。

- 同一本题会话会携带原题图片、原答案和历次成功的排错记录，按错误定位、修改位置、最小修复、验证步骤回答。
- 主窗口和悬浮窗均有回答轮次导航，可以上一轮／下一轮切换，或点击“回到原始解答”。排错生成时仍能查看原始答案；切换查看不会改变继续排错使用的完整会话。新题成功后开始新的轮次列表，退出应用清空。
- 编程题分成“解题答案”和“代码怎么讲”两个独立部分：第一部分写填写位置、代码和验证步骤，第二部分用学生能直接口述的简单语言解释思路与执行过程，不重复贴代码。排错也先给修改，再单独解释修复后的逻辑。
- 多次按 E 可连续跟进。生成中再次按 E 不重复发请求。
- 普通待发送截图与排错截图分开处理；排错不消费已累计的普通截图。清空快捷键只清空待发送截图，不结束本题对话。
- 排错失败或停止会恢复原答案，保留已经完成的会话；再次按 E 可重新截图跟进。失败／取消的半轮内容不会写入历史。
- 普通累计发送的新题在成功后替换本题会话，避免下一题混入上一题。会话仅保留在内存中，退出应用即清除。
- 会话图片总量上限 24 MiB，文本总量上限 256 KiB；超限会提示重新发送原题，不会悄悄丢失旧上下文。排错截图使用相同捕获过滤和快捷键处理，不激活窗口或显示预览。

## 悬浮答案

在“截图解题”页点击“悬浮答案”进入：主窗口收起，右侧出现可拖动、缩放的置顶答案面板。面板不成为键盘焦点窗口，生成答案时不会唤起应用。浏览器或笔记中输入时，答案仍可见。

浮窗首次采用新版布局时使用接近当前屏幕可用高度，之后记住用户调整的大小。主窗口与浮窗均上下同时显示“解题答案”和“代码怎么讲”，中间分隔条可拖动调整比例，两区独立滚动。浮窗标题旁可点击“快捷键滚动此区”，让 ⌃⌥⌘方向键控制该区域；默认滚动解题代码，不抢输入焦点。

- 截图模式下 ⌃⌥⌘Space 控制答案浮窗显示／收起；点击浮窗“主窗口”退出浮窗模式。
- 浮窗背景默认70%不透明，可在顶部滑块调到25%～100%，自动保存。只调整背景，文字和控件保持完整不透明度；窗口共享排除和非激活属性保持不变。
- ⌃⌥⌘↑／↓ 上下滚动约七成页，输入焦点不离开原应用。
- ⌃⌥⌘←／→ 左右滚动选中区域当前可见的长代码块，约七成宽度；代码保留原有格式，不自动换行。多个代码块同时可见时，优先移动显示面积最大的那一块。截图浮窗模式下这两个键不切换面试历史；返回面试模式后仍用于上一题／下一题。
- ⌃⌥⌘S 全屏、⌃⌥⌘4 区域、⌃⌥⌘Return 合并发送、⌃⌥⌘E 全屏截图排错。
- 浮窗在创建、首次显示和再次显示前都设置共享排除；普通窗口的排除开关不会解除浮窗保护。本应用自己截图时也排除整个应用，包括浮窗。
- 此标记需要录屏软件配合。腾讯会议接收端需对新面板实际复测；不能仅凭窗口属性断言所有录屏软件均不可见。继续关闭腾讯会议“视频流畅度优先”。

## 验证

```sh
./scripts/test-screen-questions.sh
```

测试图片请求格式、图文流式响应、HTTP 错误、畸形/截断/空响应，以及全屏/区域混合顺序、框选期间发送、取消与清空、失败重试、额度限制、Retina尺寸、越界/反向拖拽、显示器变化拒绝和选区面板的非激活/共享排除属性。

可选 `--live` 使用已保存的模型配置发送两张自动生成的题目上下文不完整图片，并检查解答；不会截取或发送真实桌面，也不会输出密钥。

实际全局快捷键、系统授权和腾讯会议接收端隐藏效果需在安装的应用中验证。

可选 `--live-writing` 用两张独立的合成编辑器截图检查作答位置说明：在线判题与现有 React 项目。不会发送真实桌面。

可选 `--live-simple` 使用合成 React JSX 秒表题检查基础实现风格和填写说明，不发送真实桌面。

可选 `--live-repair` 将合成原题截图、故意含错的上一轮代码、后续报错截图一并发送，检查模型是否沿同题对话定位修复，不发送真实桌面。
